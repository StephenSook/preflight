# Preflight

The call that doesn't happen.

Preflight is a pre-dial compliance interlock for the Vonage Voice API. It sits in the call-control path,
reads the call flow your own server is about to serve, and stops the call before the carrier ever sees
it if that flow would break federal or Georgia telemarketing law.

Build in progress for the DIALED IN Builder Challenge (CreateHER Fest x Vonage, Atlanta cohort).
Everything below this line is filled in from `docs/fact-sheet.md` as the build lands.
